在美國叫鎖匠開房門，依照Angi整理的2026年資料，住宅開鎖大約$75到$200，換鎖芯每個鎖約$50到$130，新鎖安裝每道門約$100到$300。汽車、夜間、週末和高安全鎖都會讓價錢往上走。下面把常見項目和影響價錢的因素一次說清楚。

我們每天在電話裡被問最多的，就是「開鎖多少錢」。這篇是我們給客人的老實答案。

## 2026年全美開鎖參考價格

以下是Angi、Thumbtack、HomeAdvisor等平台公開的全美參考範圍，不是我們的固定報價：

| 服務項目 | 全美參考價 |
|---|---|
| 住宅開鎖 | 約$75至$200 |
| 換鎖芯（每個鎖） | 約$50至$130 |
| 新鎖安裝（每道門） | 約$100至$300 |
| 輔助鎖安裝（每道門） | 約$50至$200 |
| 汽車開鎖（白天） | 約$50至$300 |
| 取出斷在鎖裡的鑰匙 | 約$50至$200 |
| 一般車鑰匙或鑰匙片 | 約$25至$150 |
| 晶片車鑰匙 | 約$100至$400 |

Thumbtack的資料則顯示，全美找鎖匠的平均花費大約在$123到$275之間。我們自己的參考價格整理在[開鎖收費標準](/pricing/)。

## 為什麼同樣是開鎖，價錢差這麼多？

上門開鎖的帳單，通常至少包含兩部分：一個人開車到現場的出勤成本，加上實際的工作，例如開鎖、換鎖芯、編程鑰匙。

再來是時段。晚上、週末和假日出勤，各家都會加價。還有鎖的種類：一般Kwikset門鎖很快就能開，Medeco這類高安全鎖芯可能要花很久，甚至需要鑽鎖。

地區也有差別。大城市的人工和交通成本比較高，郊區距離遠，出勤費也可能比較高。

## 最常見的加價陷阱

問題不在收費，而在「沒說清楚的加總」。電話裡報一個很低的服務費，到了現場才加上開鎖費、夜間費、零件費，最後的帳單是電話報價的好幾倍。

打電話時，請問這三個問題：

- 含所有費用的總價是多少？
- 我人到了現場決定不做，要付多少？
- 什麼情況下價錢會改變？

答不出來，或一直說「到了才知道」的，要特別小心。更多辨認方法，請看[如何避免開鎖詐騙](/blog/avoid-locksmith-scams/)。

## 怎麼樣可以花少一點？

能等白天就等白天。如果人和東西都安全，例如只是被鎖在外面、家裡有人可以晚點回來，白天叫鎖匠通常比半夜便宜。

被鎖在外面時，不要自己撬。撬壞門框或鎖舌，修理費常常比開鎖還貴。

搬家要換鎖時，問問換鎖芯就好。如果鎖本身沒問題，換鎖芯比整個換便宜很多。

真的急、是半夜，就直接找[24小時緊急開鎖](/services/24-hour-emergency-locksmith/)，但一樣先問總價。

## 換鎖芯一次換五個鎖，怎麼算？

很多人搬家時會一次處理全部的門。這時候要注意，報價方式有兩種：有的鎖匠收一次出勤費，再按每個鎖芯計價；有的只報「一個鎖」的價錢，五個鎖就變五倍。

打電話時直接說清楚：「大門、後門、車庫門、車庫進屋的門，加上信箱，總共五個鎖芯，全部調成同一把鑰匙，總價多少？」這樣問，對方就很難在現場再加項目。

另外，鑰匙也要問清楚。換完鎖芯通常會附兩三把新鑰匙，多配的每把是否另外收費，事先問比事後爭執好。

## 我們的做法

我們在電話裡報總價，夜間和週末的價錢也包含在裡面。到了現場發現跟描述不同，先跟您解釋，您同意才繼續。這是我們覺得在這一行該有的基本做法。
